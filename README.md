Cours : Structures de données et algorithmes
Devoir : Devoir 3 – Listes doublement chaînées

Environnement de développement utilisé :
- Système d’exploitation : Windows 11
- Environnement de développement : Visual Studio 2022
- Langage : C#
- Version .NET : .NET 8.0

Description du projet :
Ce projet implémente une liste doublement chaînée avec suppression paresseuse (lazy deletion), ainsi qu’une version alternative utilisant des nœuds sentinelles (bonus). Le programme permet :
- d’ajouter des éléments ;
- de rechercher des éléments actifs ;
- de marquer des éléments comme supprimés ;
- de compacter la liste pour retirer physiquement les éléments supprimés ;
- d’afficher les valeurs actives ;
- de tester la version avec sentinelles.

Structure des fichiers :
- Program.cs : Interface console et logique de test.
- Node.cs : Définition de la structure de nœud.
- DoublyLinkedList.cs : Liste doublement chaînée avec suppression paresseuse.
- DoublyLinkedListSentinel.cs : Version avec sentinelles (bonus).
- aminamissoum.devoir3.csproj : Fichier de configuration du projet Visual Studio.

Instructions pour exécuter le programme :
1. Ouvrir la solution dans Visual Studio.
2. Compiler le projet (Ctrl + Maj + B).
3. Exécuter le programme (Ctrl + F5 ou bouton Exécuter).
